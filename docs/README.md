# UMR Project Page

Minimal static build prepared for GitHub Pages.

## Local preview

Run a local HTTP server from this directory:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## GitHub Pages

Use this directory as the repository root, push it to GitHub, and enable Pages from the repository's default branch and `/ (root)` folder.

All required HTML, styles, scripts, videos, interactive scene files, the Viser client, and the compressed paper PDF are included. Source datasets, virtual environments, build scripts, and unused media are intentionally excluded.
